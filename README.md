# PROJECT RB

中心 + 圆形判定环的旋转音游。音符从中心扩散到圆环上，玩家按住斜弧端点、向正确方向旋转 90° 完成判定；每次旋转都会整体转动谱面，并改写屏幕键位与谱面方向的对应关系。

单文件网页原型：双击打开 `outputs/ring-beat.html` 即可游玩（电脑 / 手机浏览器均可）。

## 玩法

- 判定环：屏幕中心一点，外圈圆环；音符是落在环上的弧形判定弧。
- 45° 弧（点按）：弧落到对应方向时，按 W/A/S/D 或点触屏对应区域。
- 90° 斜弧（旋转判定）：跨两个相邻方向的弧。按住其中一个端点，并向正确方向旋转 90°——例如跨左上角的弧，按 A（左端点）逆时针转，或按 W（上端点）顺时针转，二选一。触屏为按住端点滑动。
- HOLD（长按弧）：只出现在四正方向。头部命中后保持按住，朝圆心的拖尾随按住时长推进，亮色端帽碰到头部即为松手时刻；旋转谱面时按住不中断。
- KICK（虚线弧）：按住即命中——方向持续按下、音到底线时自动判定，无过早惩罚；可出现在 hold 内（同方向）或独立出现。

## 旋转规则

- 谱面的上 / 下 / 左 / 右永远锁在圆环上，跟着环转。
- 电脑端 W/A/S/D 永远锁在屏幕方向：左滑一次后，谱面的"上"位于视野左侧，下一个正上方音符要按 A。
- 每次旋转恰好 90°，玩家自选顺 / 逆时针；0.18s 缓动动画，判定跟随动画中的位置。
- 90° 斜弧判定窗口比点按更宽（±260ms / ±145ms），保证旋转输入有足够反应时间。

## 操作

- 电脑：W/A/S/D 敲击；鼠标在圆环上拖动旋转；← / → 方向键旋转 90°；P / Esc 暂停。
- 手机：四区点按；圆环滑动旋转；切走页面自动暂停。

## 谱面与曲目

- 难度：轻松（仅 45° 点按）→ 普通（90° 斜弧 + HOLD）→ 困难（八分插音、旋转更密集）。
- 曲目：NEON SKY（124 BPM，EDM）、MIDNIGHT DRIVE（92 BPM，合成器浪潮）、HYPER POP（140 BPM）。音乐为 Web Audio 实时程序合成（和弦进行 + 鼓组 + 旋律），无第三方素材。

## 设计要点

- 旋转是被判定的**方向操作**，而非瞄准手段：90° 弧 = 端点 + 方向组合判定，与 Rotaeno 的陀螺仪体感旋转有本质区别。
- 音符只用弧线表达（无小圆点）；未命中会继续飞出圈外并淡出，错过时机一目了然。
- 谱面程序生成并遵守可打性规则：首音向上、hold 内不叠其他音符（kick 除外）、hold 尾不在同方向叠 tap、hold 不与 90° 弧同现。
- 屏幕闪光与震动刻意调弱，减少视觉打扰。

运行验证前需先从游戏本体抽取脚本（`work/game.js` 为生成产物，不入库）：

```bash
sed -n '/<script>/,/<\/script>/p' outputs/ring-beat.html | sed '1d;$d' > work/game.js
node work/verify-ring.js
```
